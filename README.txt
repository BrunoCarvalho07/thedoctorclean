# 🧼 The Doctor Clean - Limpeza e Impermeabilização de Estofados

Uma Landing Page moderna, de alta conversão e totalmente responsiva desenvolvida para a **The Doctor Clean**, empresa especializada em higienização e impermeabilização de sofás, colchões e estofamentos em São Paulo.

---

## 🚀 Recursos Principais

*   **Tema Claro e Escuro (Light/Dark Mode):** Alternância dinâmica de cores com persistência de preferência via `localStorage`.
*   **Slider Interativo Antes e Depois:** Componente interativo que permite ao usuário arrastar e comparar visualmente o resultado do serviço.
*   **Carrosséis Dinâmicos:** Exibição fluida de avaliações de clientes do Google Maps e vídeos demonstrativos dos serviços.
*   **Galeria de Resultados em Modal:** Pop-up dinâmico que carrega álbuns de fotos específicos para cada tipo de serviço clicado.
*   **Otimização para SEO Local:** Configuração avançada com dados estruturados (`JSON-LD`), Tags Open Graph e sitemap xml estruturado para motores de busca.
*   **Animações Fluídas:** Integração com a biblioteca AOS (Animation On Scroll) para revelação suave dos elementos na tela.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído puramente com tecnologias web fundamentais (Vanilla stack) para garantir máxima performance:

*   **HTML5** - Estruturação semântica e acessibilidade.
*   **CSS3** - Design responsivo baseado em Flexbox/Grid e sistema de variáveis nativas para temas.
*   **JavaScript (ES6+)** - Manipulação do DOM, controle dos carrosséis, lógica do modal e interações do usuário.
*   **FontAwesome (v6.4.0)** - Biblioteca de ícones vetoriais.
*   **AOS Library** - Efeitos de animação ao rolar a página.
